# rugen brand kit

Logo marks for rugen. Proposal page with all marks at small sizes:
https://claude.ai/artifact/RM4fZSFkNoqYNUar4KHa4K

## Colors

| Name | Hex | Use |
|---|---|---|
| Paper | `#f7f5ef` | Backgrounds, cut-outs |
| Ink | `#181816` | Letters, outlines |
| Rugen red | `#e0201e` | One accent per mark, never more |

GIMP/Aseprite palette: `palette.gpl`.

## Marks

All marks share one pixel **R**: 7 × 8 cells, 2-cell strokes.

| Mark | File | Use |
|---|---|---|
| Hit Pixel | `rugen-tile` | **Primary.** App icon, favicon, site logo. Sharp at 16 px. |
| Clsn | `rugen-clsn` | Story mark: README, docs hero, stickers. From 32 px. |
| Hanko | `rugen-seal` | Stamp: release notes, tournament badges. From 24 px. |
| Lifebar | `rugen-life` | Game UI, HUD contexts. From 32 px. |
| Impact | `rugen-burst` | Posters, social avatars. From 48 px. |
| Clash | `rugen-vs` | Letter-free versus mark. Any size. |
| Ensō | `rugen-enso` | Calm contexts: docs, About. From 24 px. |
| Six Buttons | `rugen-pad` | Arcade-flavoured abstract. From 24 px. |

## Folders

- `svg/`: every mark, `rugen-<mark>.svg` for light backgrounds, `rugen-<mark>-on-dark.svg` for dark ones.
- `png/<mark>/`: transparent PNGs at 16, 32, 48, 64, 128, 256, 512 and 1024 px.
- `favicon/`: Hit Pixel as `favicon.svg`, `favicon.ico` (16/32/48), `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`.

## Rules

- Keep clear space of one R cell (1/10 of the mark) on every side.
- Pixel marks scale by whole multiples when drawn as pixel art (nearest neighbour, no smoothing).
- Do not recolor, outline, add shadows or put the red on red.
- The wordmark is **RUGEN** set in Pixelify Sans Bold, with ルゲン as an optional subtitle.
